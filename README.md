# イベント予約システム

静的サイト（イベント一覧・詳細・予約フォーム）+ Googleスプレッドシート（Apps Script）で構成された、シンプルなイベント予約システムです。

## 構成

- `index.html` / `js/events-list.js` … イベント一覧ページ
- `event.html` / `js/event-detail.js` … イベント詳細・予約フォームページ
- `css/style.css` … 全体のスタイル
- `js/config.js` … Apps ScriptのウェブアプリURLを設定する場所
- `js/api.js` … Apps Scriptとの通信処理
- `apps-script/Code.gs` … バックエンド（スプレッドシート連携・定員管理）

予約データとイベントデータはすべてGoogleスプレッドシートに保存されます。サーバーの用意やホスティング費用は不要です（静的サイトはローカルまたは任意の静的ホスティングで公開できます）。

## セットアップ手順

### 1. スプレッドシートを作成する

1. Googleドライブで新しいスプレッドシートを作成する（例: 「イベント予約管理」）
2. メニューから「拡張機能」>「Apps Script」を開く
3. デフォルトで開かれる `コード.gs` の中身をすべて削除し、このプロジェクトの [`apps-script/Code.gs`](apps-script/Code.gs) の内容を貼り付ける
4. 上部の関数選択で `initializeSheets` を選び、実行する（初回は権限の承認が必要）
   - これにより `Events` シートと `Reservations` シートが自動作成され、以下の予約枠が21件登録されます
     - **沖縄工芸フェア「読谷山花織 機織り体験（コースター作成）」**（会場: 時事通信ホール）
     - 開催日: 2026年9月11日・12日・13日の3日間
     - 各日 10:00〜16:00 の1時間刻み（10,11,12,13,14,15,16時開始）で7枠、計21枠
     - 各枠の定員は1組（1枠1組の完全予約制）

### 2. イベントを登録・編集する

`Events` シートに直接行を追加・編集してイベント（予約枠）を管理します。列は以下の通りです。

| 列 | 説明 |
|---|---|
| id | イベントを一意に識別するID（例: `event-2026-09-01`）。URLの一部になります |
| title | イベント名 |
| date | 開催日（例: `2026-09-01`） |
| time | 開催時刻（例: `13:00`） |
| venue | 会場名 |
| description | イベント説明（改行可） |
| imageUrl | イベント画像のURL（任意、空欄可） |
| capacity | 定員（数値） |

`Reservations` シートには予約が入るたびに自動で行が追加されます。手動で編集する必要はありません（キャンセル処理をしたい場合は該当行の `status` を `confirmed` から別の値に変更してください。定員カウントから除外されます）。

### 3. ウェブアプリとしてデプロイする

1. Apps Scriptエディタで右上の「デプロイ」>「新しいデプロイ」をクリック
2. 種類の選択で「ウェブアプリ」を選ぶ
3. 設定:
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **全員**
4. 「デプロイ」をクリックし、発行された **ウェブアプリURL**（`https://script.google.com/macros/s/xxxxx/exec`）をコピーする

コードを変更した場合は、再度「デプロイ」>「デプロイを管理」から新しいバージョンを反映してください。

### 4. フロントエンドにURLを設定する

[`js/config.js`](js/config.js) を開き、コピーしたURLを設定する。

```js
const APPS_SCRIPT_URL = "https://script.google.com/macros/s/xxxxx/exec";
```

### 5. 動作確認

`index.html` をブラウザで開く（ローカルで開く場合は、ブラウザのセキュリティ設定によりVS Codeの Live Server 等の簡易サーバー経由での閲覧を推奨します）。イベント一覧が表示され、詳細ページから予約が行えれば成功です。

## 定員管理の仕組み

- 予約送信時、Apps Script側で `LockService` によるロックを取得し、現在の予約合計人数を再計算した上で定員と比較します。これにより、複数人が同時に予約しても定員を超過しないようになっています。
- 一覧・詳細ページには残り人数がリアルタイム（アクセス時点）で表示され、残りわずか・満席のバッジが自動的に切り替わります。

## 公開する場合

このサイトは静的ファイルのみで構成されているため、Netlify、Vercel、GitHub Pages、または任意のレンタルサーバーにそのままアップロードして公開できます。Apps Script側の設定変更は不要です。
